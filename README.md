# RustyConfigLib (RCL)

A modern, highly customizable configuration and GUI library for Minecraft Rust Client / Modding Frameworks, inspired by [YetAnotherConfigLib (YACL)](https://github.com/isXander/YetAnotherConfigLib).

## Workspace Structure
- `crates/rcl-core`: Core data structures, option management, serialization, and listeners.
- `crates/rcl-macros`: Procedural derive macros (`#[derive(Config)]`).
- `crates/rcl-gui`: GUI renderer abstractions and modular widgets.
- `examples/sample-mod`: Example implementation demonstrating how to configure mod settings.
